# React + TypeScript Projects: Flipkart Clone & Quizzes App

This repository contains two separate React projects developed using **TypeScript**:

1. **Flipkart Clone**: A UI clone of the popular e-commerce platform, Flipkart, built with React and TypeScript.
2. **Quizzes App**: A quiz application that allows users to attempt multiple quizzes, track their scores, and navigate through questions.

## Flipkart Clone

### Overview
The Flipkart Clone is a simplified e-commerce platform designed to replicate the look and feel of the Flipkart website. This app includes product listings, product details pages, and a basic shopping cart functionality.

### Features
- **Responsive Layout**: Designed using Flexbox and CSS Grid for responsiveness, adapting to different screen sizes.
- **Product Listing**: Displays a list of products with images, names, and prices.
- **Product Details Page**: A dedicated page for each product with additional information.
- **Shopping Cart**: Users can add and remove products from a shopping cart, stored in LocalStorage for persistence.
- **Search Bar**: A search bar for filtering products based on names.

### Technologies Used
- **React**: Frontend library to build UI components.
- **TypeScript**: Provides type safety and better developer experience.
- **CSS3**: Used for styling, including Flexbox and Grid for layout and media queries for responsiveness.
- **React Router**: For navigation between pages like product listing and product details.
- **LocalStorage**: For cart persistence across page reloads.
- **Redux**: For state managements.

## Quizzes App

### Overview
The Quizzes App is an interactive quiz platform where users can select quizzes, answer multiple-choice questions, and track their progress. It includes features like a timer, score calculation.

### Features
- **Multiple Quizzes**: Users can choose from different quiz categories.
- **Timer**: Each quiz has a countdown timer.
- **Score Calculation**: After completing a quiz, users can view their score and the correct answers.


### Technologies Used
- **React**: For building the quiz UI components.
- **TypeScript**: For type checking and to ensure proper handling of quiz data.
- **CSS3**: For styling the quiz interface, transitions, and animations.

---

## Technologies Used

- **React**: A JavaScript library for building user interfaces.
- **TypeScript**: Adds type safety to JavaScript, enhancing code quality and developer productivity.
- **CSS3**: Styling techniques such as Flexbox, Grid, and media queries for responsive layouts.
- **React Router**: Routing library for navigating between different pages/components in the app.
- **LocalStorage**: For persisting data like cart contents and quiz progress.
